# Manager Approval Workflow

## PTO Carryover Request Flow

1. Employee submits a carryover request in the HR portal.
2. The request must include the current unused balance, requested carryover days, and a reason code.
3. The direct manager reviews the request for team coverage and operational necessity.
4. If the request is for 5 days or fewer and is submitted before December 31, the manager may approve it directly in the portal.
5. If the request exceeds 5 days, the portal automatically routes the request to HR after manager approval.
6. HR reviews routed requests for documented business continuity impact, blackout periods, or leave-administration constraints.
7. The final decision is recorded in the portal and emailed to the employee.

## Documentation Requirements

Manager-approved requests should include the number of days approved and a short operational justification.

HR-reviewed exceptions should also attach supporting notes describing the business impact, affected calendar window, and any leadership direction that limited time off.

Employees must use approved carryover by March 31 of the following year unless a separate HR note lists a different expiration date.
