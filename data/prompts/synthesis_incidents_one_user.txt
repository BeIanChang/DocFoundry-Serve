Question: Summarize the retry-related issue behind the billing worker incident.

Sources:
[D1] Deployment Notes - April 17
[S1] The retry change increased the per-job retry cap from 2 attempts to 6 attempts and reduced the wait time between retries.
[D2] Known Issues
[S2] Aggressive retries can amplify pool contention and create elevated write latency even when database CPU remains under control.
[D3] Incident Postmortem - API Latency Spike
[S3] The new worker logic retried failed writes too aggressively and increased concurrent DB usage.

Context:
[S1] The retry change increased the per-job retry cap from 2 attempts to 6 attempts and reduced the wait time between retries.

[S2] Aggressive retries can amplify pool contention and create elevated write latency even when database CPU remains under control.

[S3] The new worker logic retried failed writes too aggressively and increased concurrent DB usage.
